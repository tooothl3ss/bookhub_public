# Безопасность и данные

BookHub предназначен для одного владельца и доверенной домашней сети.
Веб-полка на порту 8088 не проверяет пароль. Она позволяет читать и скачивать книги,
менять и удалять данные, запускать ИИ и обращаться к настроенному устройству X3.

Порт 8089 предоставляет синк и OPDS с авторизацией, но не веб-полку. Авторизация этого
порта не защищает порт 8088. Защита Origin/CORS ограничивает запросы чужих веб-страниц,
но не заменяет контроль доступа. Для внешнего доступа используй VPN либо HTTPS-прокси
с авторизацией и настройками, совместимыми с твоими читалками.

По умолчанию Compose привязывает оба порта к `127.0.0.1`. Скрипт настройки создаёт два
разных случайных секрета, файл `.env` с правами 0600 и не выводит секреты на экран.
Не публикуй `.env`, `kindle-client/config.json`, `data/` и их резервные копии.

Все книги, позиции, данные устройств, обзоры и настройки каталога хранятся локально в
`data/`. Проект не включает книги и рабочие данные автора. При использовании функций:

- поиск метаданных отправляет названия и авторов в OpenLibrary/Wikidata, а перевод
  поискового запроса может обращаться к Google Translate (`TRANSLATE_TITLES=0` отключает его);
- ручные запросы ИИ передают настроенному сервису названия, описания и/или сведения о полке
  и предпочтениях в зависимости от функции; сервис может тарифицировать запросы;
- Kindle передаёт серверу файлы KFX для обработки и текущую позицию;
- ручная передача на X3 отправляет выбранный EPUB на адрес `X3_URL`.

Не прикладывай токены, реальные книги, базы и полные журналы к публичным issue.
Для сообщения об уязвимости используй приватное сообщение владельцу репозитория либо
GitHub Private Vulnerability Reporting, если эта возможность включена. Публичный снимок
поддерживается по возможности, гарантированного срока исправления нет.
