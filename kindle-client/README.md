# Клиент Kindle

Клиент отправляет BookHub список книг, KFX и место чтения; получает карты позиций и применяет
более дальнее место чтения из общей библиотеки. Работает с нативным Kindle Reader.
**DRM не обходится.** Для обычной EPUB-библиотеки или KOReader этот клиент не требуется.

Нужен подготовленный Kindle с доступом к shell и системными утилитами `sqlite3`, `curl`,
`tar`, `sha256sum`, LIPC. Поддержка всех моделей и прошивок не гарантируется: чтение `.yjf`
и события сна зависят от устройства. Перед первым использованием сохрани копию своих данных.

## Установка

1. Укажи в `.env` сервера адрес домашней сети в `BOOKHUB_BIND` и запусти BookHub по корневому README.
2. Создай рядом с этим файлом `config.json` из `config.example.json`. В `server` укажи адрес
   сервера, доступный с Kindle; в `api_key` — значение `SYNC_API_KEY` из серверного `.env`.
   Для нескольких Kindle задай каждому собственный `device_id`.
3. Скопируй содержимое `kindle-client/` в `/mnt/us/kindle-sync/` на Kindle.
4. В shell Kindle выполни:

```sh
chmod +x /mnt/us/kindle-sync/bin/kindle-agent /mnt/us/kindle-sync/bin/kindle-pos /mnt/us/kindle-sync/bin/luajit
/mnt/us/kindle-sync/bin/kindle-agent doctor
/mnt/us/kindle-sync/bin/kindle-agent start
/mnt/us/kindle-sync/bin/kindle-agent status
```

При обновлении сначала выполни `kindle-agent stop`, замени файлы программы, сохранив
`config.json`, `maps/` и `state/`, затем запусти агент снова. Не публикуй эти три каталога/файла:
в них секреты, сведения о книгах и неотправленные позиции.

## Работа

- `doctor` проверяет окружение и связь; `scan` отправляет инвентарь; `sync` выполняет один проход.
- `start`, `stop`, `status` управляют фоновым агентом.
- При сне/закрытии крышки агент закрывает открытую книгу через библиотеку, дожидается записи
  позиции и пытается отправить её. При отсутствии сети позиция ждёт следующей связи.
- При получении более дальней позиции агент закрывает книгу и применяет новое место.
  Автоматически обратно книгу не открывает.
- Карты загружаются с сервера. Проценты приблизительные; сопоставление использует текст и PID.
- Автозапуска после перезагрузки Kindle нет: `kindle-agent start` запускается вручную.

Журнал находится в `state/agent/agent.log`. После пробуждения сеть может появиться не сразу;
следующий проход повторит запрос.

## LuaJIT и лицензии

Включён ARM-бинарник LuaJIT, сообщающий версию `2.1.1783773675`. Он перенесён из ранее
работавшего клиента; рецепт сборки именно этого бинарника не сохранён. Это не универсальная
сборка для любых Kindle. При несовместимости нужен подходящий LuaJIT в `bin/luajit`.
Исходники LuaJIT доступны у [разработчика](https://github.com/LuaJIT/LuaJIT/tree/v2.1).

Полные лицензии и сведения об авторах — в [LICENSES.md](LICENSES.md).
