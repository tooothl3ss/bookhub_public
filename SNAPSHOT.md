# Публичный снимок

- Подготовлен: 2026-10-08.
- Исходная ревизия приложения: `f571ca0f825d44c1788eb5b87c631e615e389a96`.
- Состояние: ранняя версия для самостоятельной установки.

Основная разработка ведётся отдельно. Публичный репозиторий получает редкие снимки;
он не является зеркалом внутренней истории и не обещает фиксированного графика релизов.
Ссылка на внутренний репозиторий для установки и работы не нужна.

В этом снимке сохранены приложение, клиент Kindle и тесты. Упаковка для самостоятельной
установки включает единый `.env`, Compose без операций Git, создание случайных секретов,
отдельную документацию и лицензии. Внутренний деплой и личные данные не включены.

Ошибки можно описать в issue: приложи ревизию публичного репозитория, модель читалки,
версию прошивки, шаги воспроизведения и обезличенный фрагмент ошибки.
Исправление сначала может появиться в основной разработке и войти в следующий снимок.
